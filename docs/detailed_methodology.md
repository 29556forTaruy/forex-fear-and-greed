# Fear & Greed Index 詳細解説書

CNN の株式版 Fear & Greed Index の仕組みを解き明かし、それを為替（FX）に翻案した
**Forex Fear & Greed Index** の設計・計算方法を詳細に解説する。

---

## 第1部: CNN Fear & Greed Index（株式版・原典）

### 1.1 概要

CNN Fear & Greed Index は、**株式市場の投資家心理**を 0〜100 の1つの数値に凝縮する指標。
2012年春に CNNMoney が考案した。

| スコア | 状態 |
|--------|------|
| **0** | Extreme Fear（極度の恐怖） — 投資家が過度に弱気・狼狽 |
| **50** | Neutral（中立） |
| **100** | Extreme Greed（極度の強欲） — 投資家が過度に強気・楽観 |

背景にある考え方は、「**恐怖**が行き過ぎると価格は本来価値より下に押し下げられ、
**強欲**が行き過ぎると価格は吊り上げられる」というもの。つまり逆張りのセンチメント指標として
使われることが多い（極度の恐怖 = 買い場の候補、極度の強欲 = 警戒すべき局面）。

### 1.2 7つの構成要素

CNN は **7つの下位指標**をそれぞれ 0〜100 に正規化し、**等加重（単純平均）**で合成する。
すべての要素は「**高いほど強欲（Greed）**」になるよう、必要なものは符号を反転させる。

#### 要素1: Market Momentum（市場モメンタム）

- **何を測るか**: 株式相場が地合い対比で上か下か
- **入力データ**: S&P 500 指数とその **125日（約6ヶ月）移動平均**
- **計算**: `S&P 500 − 125日移動平均`
- **解釈**: 価格がMA125より上 → 上昇トレンド → **強欲**（高スコア）、下 → **恐怖**（低スコア）
- **反転**: 不要（MA上抜け = 強気 = そのまま高スコア）

#### 要素2: Stock Price Strength（価格の強さ）

- **何を測るか**: 幅広い銘柄の強弱（market breadth）
- **入力データ**: NYSE（ニューヨーク証券取引所）の **52週新高値銘柄数 − 52週新安値銘柄数**
- **計算**: 新高値超過 = 多くの銘柄が強い = 強欲、新安値超過 = 弱い銘柄が多い = 恐怖
- **反転**: 不要

#### 要素3: Stock Price Breadth（出来高の幅）

- **何を測るか**: 出来高の推進力の方向
- **入力データ**: NYSE 上昇銘柄の出来高 vs 下落銘柄の出来高
- **計算**: **McClellan Volume Summation Index**
  - まず McClellan Oscillator = 上昇−下落出来高の 約19日EMA と 約39日EMA の差
  - これを日々累積（Summation）したもの
- **解釈**: 上昇出来高が支配的 → Summation 上昇 → 強欲
- **反転**: 不要

#### 要素4: Put and Call Options（プット/コール比率）

- **何を測るか**: オプション市場の弱気・強気バイアス
- **入力データ**: CBOE の **総（equity + index）プット/コール比率の5日移動平均**
- **計算**: プット/コール比率が高い = プット買い（下落保険）が多い = 弱気 = 恐怖
- **反転**: **必要**（比率↑ = 恐怖なので、スコア = 100 − 正規化値）
- **補足**: 「1.0 が境界」とよく言われるが、実際はCNN独自の相対的正規化

#### 要素5: Market Volatility（ボラティリティ）

- **何を測るか**: 予想変動率（「恐怖指数」）
- **入力データ**: **VIX**（S&P 500のインプライド・ボラティリティ）とその **50日移動平均**
- **計算**: VIX が 50日MA より高い → 恐怖 → 低スコア
- **反転**: **必要**（VIX↑ = 恐怖なので反転）

#### 要素6: Safe Haven Demand（安全資産需要）

- **何を測るか**: 株式 vs 債券のローテーション
- **入力データ**: 過去20営業日の **株式リターン − 国債リターン**
- **計算**: 株が債券に勝っていれば → リスク選好 → 強欲、債券優位 → 恐怖
- **反転**: 不要

#### 要素7: Junk Bond Demand（ジャンク債需要）

- **何を測るか**: 信用リスクの選好度
- **入力データ**: **ハイイールド債 − 投資適格債の利回り差**（信用スプレッド）
- **計算**: スプレッド縮小 → リスク選好 → 強欲、拡大 → 恐怖
- **反転**: **必要**（スプレッド↑ = 恐怖なので反転）

### 1.3 正規化

各指標の現在値を 0〜100 にマッピングする工程。CNN は正確な窓・数式を**公開していない**。
第三者による再現では以下のいずれかが使われる:

- **z-score 方式**: `(現在値 − 過去平均) / 標準偏差` を計算し、正規分布の CDF で 0〜100 にマッピング
- **trailing percentile 方式**: 直近 N 営業日（1〜3年）における現在値の順位を百分率で表す

どちらも「過去と比べて今がどれくらい極端か」を数値化する。CNN の実際の手法は z-score に
近い標準化と推定されるが、窓の長さやクリッピングの詳細は非公開。

### 1.4 集約

```
headline = (要素1 + 要素2 + 要素3 + 要素4 + 要素5 + 要素6 + 要素7) / 7
```

**等加重の単純平均**。重み付けの傾斜はない。

### 1.5 ラベル境界

| 範囲 | 英語ラベル | 日本語 |
|------|-----------|--------|
| 0〜24 | Extreme Fear | 極度の恐怖 |
| 25〜44 | Fear | 恐怖 |
| 45〜55 | Neutral | 中立 |
| 56〜75 | Greed | 強欲 |
| 76〜100 | Extreme Greed | 極度の強欲 |

### 1.6 更新頻度

- ライブの headline 値は**米国市場の取引時間中に随時更新**（intraday）
- 履歴は**日次（引け値ベース）**
- 5日平均・20日リターン・移動平均などの平滑化入力があるため、急変への反応にはラグがある

### 1.7 限界と批判

1. **遅行指標**: 既に起きたこと（過去の価格・出来高・オプション）の要約であり、将来予測力は限定的
2. **逆張りの地合い計**であって割安/割高の判定ツールではない
3. **透明性の欠如**: 正確な式・正規化窓を非公開 → 第三者再現にばらつき
4. **入力の相関**: 7要素中の多くが S&P の値動きに連動 → 実質的に「方向性モメンタム」を過大評価しがち
5. あくまで**多数ある入力の1つ**（投資助言ではない）

### 1.8 まとめ: CNN 指数の本質

CNN Fear & Greed Index は「**複数の市場センチメント指標を正規化して平均する**」という、
概念的にはシンプルな仕組み。その価値は:
- 異なる市場（株・債券・オプション・ボラティリティ）の信号を**1つの数値に圧縮**する点
- 「今の市場心理は歴史的にどれくらい極端か」を直感的に伝える点

にある。ただし、7要素の多くが株価と相関するため、**独立した7つの意見**というよりは
**同じテーマの7つの角度**という方が正確。

## 第2部: Forex Fear & Greed Index（為替版・本プロジェクト）

### 2.1 翻案の背景と目的

CNN の手法を**為替市場に適用**する。株式専用の要素（NYSE新高値安値、McClellan、
プット/コール比率等）は為替に直接対応物がないため、為替固有の代替指標に置き換える。

**目的**: 特定の通貨ペアについて「今の市場心理はリスクオンかリスクオフか」を
0〜100 の数値で表す。まず USD/JPY から始め、6通貨ペアに拡張済み。

### 2.2 最重要: 符号規約（リスク選好型）

円は**安全通貨（セーフヘイブン）**。世界的な恐怖（リスクオフ）は円**高**を生む。
これは株式の「恐怖 = 株価下落」とは方向が異なる。

本指数の定義:

| スコア | 状態 | 為替の動き |
|--------|------|-----------|
| **0** = Extreme Fear | リスクオフ | **円高** / USD/JPY **下落** / キャリー巻き戻し |
| **50** = Neutral | 中立 | 方向感なし |
| **100** = Extreme Greed | リスクオン | **円安** / USD/JPY **上昇** / キャリー過熱 |

> 副次効果: **極端な強欲（76〜100）は「キャリー過熱・反転リスク」の警告**にもなる。
> 過去の巻き戻し（例: 2024年8月）は、極端な円ネットショート＋薄いキャリー対ボラ比で起きた。

すべての構成要素は「**高スコア = Greed = リスク選好 = ペア上昇圧力**」に統一する。

### 2.3 正規化方式: ローリング・パーセンタイル

CNN（推定 z-score）とは異なり、本指数では **trailing percentile（後追い百分位数）**を採用する。

#### 計算方法

各時点 t において、生シグナル `x_t` の直近 252 営業日（= 約1年）における順位を百分率で返す:

```
percentile_t = 100 × (x_t 以下のデータ数 + 0.5 × 同値数) / 有効データ数
```

- 窓（window）: **252 営業日**（約1年）
- 最小データ数（min_periods）: **60 営業日**（約3ヶ月）— これ未満は NaN
- tie（同値）の扱い: 「以下」と「同値」の半分をカウント（平均的な順位を返す）

#### z-score ではなくパーセンタイルを選んだ理由

z-score は `(x − μ) / σ` で標準偏差を使うため、分布の形に敏感。為替市場では
**レジーム変化**が頻繁に起きる（例: 日米金利差が2022〜2024で525bp→2026で250〜300bp
に圧縮）。z-score だと、レジーム変化後の「新しい普通」が長期間「異常」と判定されてしまう。
パーセンタイルは順位のみを見るため、レジーム変化に頑健。

#### 反転が必要な要素

「高い値 = 恐怖」の要素（例: ボラティリティ）は反転する:
```
score = 100 − percentile
```

### 2.4 7つの構成要素（詳細）

| # | 要素名 | 重み | 反転 | 概要 |
|---|--------|------|------|------|
| 1 | モメンタム | 0.18 | 否 | 価格 vs 125日移動平均 |
| 2 | 52週レンジ位置 | 0.12 | 否 | 年間の高値〜安値レンジ内の位置 |
| 3 | 実現ボラ（通貨VIX） | 0.18 | **是** | 20日実現ボラティリティ |
| 4 | 金利差＆勢い | 0.18 | 否 | base−quote の金利差と変化率 |
| 5 | クロスアセット・リスク | 0.14 | 否 | AUDJPY/日経/S&P/VIX の複合 |
| 6 | 投機筋ポジション（COT） | 0.10 | 否 | CFTC先物の非商業ネット |
| 7 | JPY-strength breadth | 0.10 | 否 | クロス円の上昇広がり（JPYペアのみ） |

合計: 1.00

#### 要素1: モメンタム（weight: 0.18）

**CNN の Market Momentum の直接翻案。**

- **生シグナル**: `(price − MA125) / MA125`
  - `price` = 通貨ペアの日次終値
  - `MA125` = 125日（約6ヶ月）単純移動平均
- **スコア化**: 生シグナルの直近252日パーセンタイル（0〜100）
- **解釈**:
  - 価格がMA125を大きく上回る → 上昇トレンド → リスクオン → **高スコア（Greed）**
  - 価格がMA125を大きく下回る → 下降トレンド → リスクオフ → **低スコア（Fear）**
- **データ源**: yfinance（日次終値）

```
例: USD/JPY = 155, MA125 = 150 の場合
  raw = (155 − 150) / 150 = 0.0333
  → 直近1年で 0.0333 が上位20%の水準なら score ≈ 80（強欲）
```

---

#### 要素2: 52週レンジ位置（weight: 0.12）

**CNN の Stock Price Strength の翻案。** 個別銘柄の新高値/新安値を数える代わりに、
通貨ペア自体の年間レンジ内の位置を使う。

- **生シグナル**: `(price − 252日安値) / (252日高値 − 252日安値)`
  - 0 = 過去1年の安値圏
  - 1 = 過去1年の高値圏
- **スコア化**: そのまま ×100（パーセンタイル化は不要、既に 0〜100）
- **解釈**:
  - 年初来高値圏 → 円安進行中 → **高スコア（Greed）**
  - 年初来安値圏 → 円高進行中 → **低スコア（Fear）**
- **データ源**: yfinance（日次終値）

```
例: USD/JPY = 155, 252日高値 = 161, 252日安値 = 140 の場合
  score = (155 − 140) / (161 − 140) × 100 = 71.4（強欲）
```

---

#### 要素3: 実現ボラティリティ / 通貨VIX（weight: 0.18, 反転）

**CNN の Market Volatility（VIX）の翻案。** FX にはCBOE VIXのような無料の
インプライド・ボラティリティ源がないため、**実現ボラティリティ**で代用する。

- **生シグナル**: 20日実現ボラティリティ（年率換算）
  ```
  RV20 = stdev(日次log return, 20日) × √252
  ```
  - 日次 log return = `ln(price_t / price_{t-1})`
  - 20日の標準偏差（母集団, ddof=0）を取り、√252 で年率化
  - 例: 値 0.094 = 年率 9.4%
- **スコア化**: パーセンタイル化した後、**反転**（100 − percentile）
- **解釈**:
  - 高ボラ = 市場の動揺 = **恐怖** → 反転して**低スコア**
  - 低ボラ = 穏やか = **強欲（リスクオン）** → 反転して**高スコア**
- **データ源**: yfinance（日次終値から算出）

```
例: RV20 = 12.5%（年率）が直近1年で上位90%なら
  percentile = 90 → score = 100 − 90 = 10（恐怖）
```

**なぜ実現ボラなのか（限界の明示）**:
- CBOE JYVIX（円のインプライドボラ指数）は実質終了
- Bloomberg/Refinitiv の CVIX, VXY は有料端末限定
- OTC FX オプションの ATM ボラ / 25Δリスクリバーサルも有料
- → 無料で取得可能な**実現ボラ**を「通貨VIX」として使う
- 限界: 終値ベースで日中レンジを過小評価 / 後ろ向き指標 / スキュー情報なし

#### 要素4: 金利差＆勢い（weight: 0.18）

**CNN の Safe Haven Demand + Junk Bond Demand を金利の観点で翻案。**
為替の最大の駆動力の一つであるキャリー（金利差）を捉える。

- **生シグナル**: base通貨 − quote通貨 の利回り差（2年債と10年債）
  - USD/JPY の場合: `米国債利回り − 日本国債利回り`
  - 2つのテナー（2Y: 政策金利期待, 10Y: 期間プレミアム/実質金利）を使用
- **スコア化**: 4つのサブスコアの平均
  1. 10Y金利差の **水準** のパーセンタイル
  2. 10Y金利差の **60日変化率** のパーセンタイル
  3. 2Y金利差の **水準** のパーセンタイル
  4. 2Y金利差の **60日変化率** のパーセンタイル
- **解釈**:
  - 金利差が大きい/拡大中 → キャリーが魅力的 → ペア上昇支援 → **高スコア（Greed）**
  - 金利差が小さい/縮小中 → キャリー魅力低下 → **低スコア（Fear）**
- **データ源**:
  - 米国債: 米財務省 日次 CSV（無料・キー不要）
  - 日本国債: 財務省(MoF) JGB CSV（無料・キー不要、Shift-JIS / 和暦）
  - EUR/GBP/AUD: FRED API（無料キー必要）
- **フォールバック**: quote通貨の利回りが欠損時は base通貨のみで代用（絶対水準）

```
例: 米10Y = 4.5%, 日10Y = 1.2% → 金利差 = 3.3%
  この 3.3% が直近1年で上位60%なら level_score = 60
  60日前の金利差が 3.0% → 変化 = +0.3%
  この +0.3% が直近1年で上位70%なら roc_score = 70
  → 10Yサブスコア = (60 + 70) / 2 = 65
  2Yも同様に計算 → 最終 rate_diff_score = 全サブスコアの平均
```

#### 要素5: クロスアセット・リスク（weight: 0.14）

**CNN の Safe Haven Demand を広義に翻案。** 株・VIX・リスク通貨を横断的に見て、
グローバルなリスク選好度を測る。全ペア共通。

- **生シグナル**: 4つのサブ指標の平均
  1. **AUD/JPY のモメンタム**: `(AUDJPY − MA60) / MA60` のパーセンタイル
     - AUD/JPY は「リスクの先行指標」として有名（リスクオン = AUD↑JPY↓ = AUDJPY↑）
  2. **日経225のモメンタム**: `(日経 − MA125) / MA125` のパーセンタイル
  3. **S&P 500のモメンタム**: `(S&P − MA125) / MA125` のパーセンタイル
  4. **VIX（反転）**: VIX のパーセンタイルを反転（100 − percentile）
     - VIX↑ = 恐怖 → 反転して低スコア
- **解釈**:
  - AUDJPY/日経/S&P が好調 + VIX が低い → リスクオン → 円安要因 → **高スコア（Greed）**
  - 各市場が軟調 + VIX が高い → リスクオフ → 円高要因 → **低スコア（Fear）**
- **データ源**: yfinance（^VIX, ^N225, ^GSPC, AUDJPY=X）

#### 要素6: 投機筋ポジション / COT（weight: 0.10）

**CNN にはない為替固有の要素。** CFTC（米商品先物取引委員会）の COT レポートから
投機筋（非商業部門）のポジションを使う。

- **生シグナル**: ペアの符号付き合成ネットポジション
  ```
  cot_signal = (+base通貨のネット) + (−quote通貨のネット)
  各通貨のネット = 非商業ロング − 非商業ショート（CME先物、対USD）
  ```
  - USD は numéraire（先物がない）のため寄与ゼロ
  - 例（USD/JPY）: `0 + (−JPYネット)` = `−JPYネット`
    - 投機筋が円をネットショート（= ドル/キャリーロング）→ cot_signal が正
  - 例（EUR/JPY）: `+EURネット + (−JPYネット)`
- **スコア化**: **156週（= 3年 × 52週）**のパーセンタイル
  - COT は週次データのため、日次の252日窓ではなく週次ベースの窓を使用
  - 156週 × 5営業日 = 780日窓、最小データ数 = 97日
- **解釈**:
  - 投機筋がペア上昇方向に大きく賭けている → **高スコア（Greed）**
  - 投機筋がペア下落方向に大きく賭けている → **低スコア（Fear）**
- **データ源**: CFTC Socrata API（無料・キー不要、週次・火曜報告日）
- **注意点**:
  - 公表ラグあり（火曜基準 → 金曜公表）
  - 極端なスコア（95以上）は**反転リスクの警告**として読むべき
    - 2024年7月: COT ≈ 99（極端な円ショート）→ 8月に巻き戻し

```
例（USD/JPY）:
  JPYネットポジション = −100,000枚（投機筋が円を10万枚ショート）
  cot_signal = −(−100,000) = +100,000
  直近3年で +100,000 が上位95%なら score = 95（極度の強欲 / 反転警告）
```

#### 要素7: JPY-strength breadth（weight: 0.10, JPYクロスのみ）

**CNN の Stock Price Breadth の翻案。** 個別銘柄の出来高幅の代わりに、
クロス円バスケットの「上昇広がり」を見る。

- **生シグナル**: クロス円バスケットのうち、20日モメンタムが正（= 円安方向）の割合
  - バスケット: USDJPY, EURJPY, GBPJPY, AUDJPY, CADJPY, CHFJPY（6通貨）
  - 各ペアの20日変化率 > 0 なら「円安方向に上昇中」
  - `breadth_pct = 上昇中のペア数 / 6`（0〜1）
- **スコア化**: `breadth_pct` の直近252日パーセンタイル
- **解釈**:
  - 多くのクロス円が上昇 → **広範な円安** → リスクオン → **高スコア（Greed）**
  - 多くのクロス円が下落 → **広範な円高** → リスクオフ → **低スコア（Fear）**
- **適用範囲**: **JPY クロスのみ**（USDJPY, EURJPY, GBPJPY, AUDJPY）
  - EURUSD, GBPUSD には適用しない（NaN → 重み再正規化で自動除外）
- **データ源**: yfinance（各クロス円の日次終値）

```
例: ある日に USDJPY↑ EURJPY↑ GBPJPY↓ AUDJPY↑ CADJPY↑ CHFJPY↓ の場合
  breadth_pct = 4/6 = 0.667
  直近1年で 0.667 が上位75%なら score = 75（強欲）
```

---

### 2.5 集約: 加重平均 + 欠損時の重み再正規化

```
FearGreed_t = Σ(w_i × score_i) / Σ(w_i)    ← その時点で利用可能な要素のみ
```

- **要素が欠損（NaN）の場合**: その要素を分子・分母の両方から除外し、
  残りの要素の重みだけで合計が1になるよう**自動再正規化**する
- これにより、FREDキーがなくて金利差が取れない場合や、
  EURUSD で breadth が NaN の場合でも、指数は残りの要素で正しく計算される

```
例: breadth が NaN（EURUSD）の場合
  利用可能な重み: 0.18 + 0.12 + 0.18 + 0.18 + 0.14 + 0.10 = 0.90
  headline = (各スコア × 各重み の合計) / 0.90
```

### 2.6 ラベル境界

CNN と同じバンドを使用:

| 範囲 | 英語 | 日本語 |
|------|------|--------|
| 0〜24 | Extreme Fear | 極度の恐怖（リスクオフ） |
| 25〜44 | Fear | 恐怖 |
| 45〜55 | Neutral | 中立 |
| 56〜75 | Greed | 強欲 |
| 76〜100 | Extreme Greed | 極度の強欲（リスクオン） |

### 2.7 通貨VIX（実現ボラゲージ）の表示

指数の要素3と同一の値を、ダッシュボード上では別パネルでも表示する:

- **主指標**: RV20（20日年率実現ボラ）を % で表示
- **副線**: 株式の VIX（^VIX）をオーバーレイ
- 1年パーセンタイルのバッジ + Calm / Normal / Stressed ラベルで文脈を提供

### 3.1 データ源一覧

すべて**無料・APIキー不要**（FRED のみ任意キー）:

| データ | 源 | キー | 頻度 | 備考 |
|--------|-----|------|------|------|
| 為替レート（6ペア） | yfinance | 不要 | 日次 | `USDJPY=X` 等 |
| VIX / S&P500 / 日経225 | yfinance | 不要 | 日次 | `^VIX`, `^GSPC`, `^N225` |
| AUD/JPY / 金 | yfinance | 不要 | 日次 | `AUDJPY=X`, `GC=F` |

| 米国債利回り（2Y/10Y） | 米財務省 CSV | 不要 | 日次 | 年別 CSV を結合 |
| 日本国債利回り（2年/10年） | 財務省(MoF) CSV | 不要 | 日次 | cp932、和暦 |
| CFTC 投機筋ポジション | CFTC Socrata API | 不要 | 週次 | 非商業ネット |
| EUR/GBP/AUD 利回り | FRED API | **任意** | 月次 | 無料キー発行可 |

### 3.2 データ統合の流れ

```
                    ┌──── prices.py ──── yfinance ──── 6ペア + VIX + 日経 + S&P + AUDJPY + 金
                    │
build_dataset() ────┼──── rates.py ───── 米財務省 CSV ──── 米2Y/10Y
  (load.py)         │                    MoF JGB CSV ───── 日2年/10年
                    │                    FRED API ──────── EUR/GBP/AUD 10Y（任意）
                    │
                    ├──── positioning.py ── CFTC Socrata ── 通貨別ネットポジション
                    │
                    └──── breadth 算出 ── yfinance ──── クロス円6ペア
                    
                    ↓
        ペアの営業日グリッドに統合（ffill: 価格5日/金利45日/COT 10日）
                    ↓
        DataFrame: price, vix, sp500, nikkei, audjpy, gold,
                   base_2y, base_10y, quote_2y, quote_10y,
                   cot_signal, breadth_pct
                    ↓
        fng/components.py → 7要素スコア（各 0〜100）
                    ↓
        fng/index.py → headline Fear & Greed（0〜100）+ ラベル
```

### 3.3 特殊なデータ処理

**和暦パース（MoF JGB データ）**:
- 財務省のJGB利回りCSVは Shift-JIS（cp932）エンコーディングで、日付が和暦（例: `R8.5.29`）
- 元号の変換テーブル: M=明治(1867+), T=大正(1911+), S=昭和(1925+), H=平成(1988+), R=令和(2018+)
- `R8.5.29` → 令和8年5月29日 → 2026年5月29日

**COT 重複日の処理**:
- CFTC は同一報告日に複数行（異なる限月・改訂）を返すことがある
- 最新のもの（`keep="last"`）のみ採用

**ffill の制限**:
- 価格: 最大5日（休場対応）
- 金利: 最大45日（月次FREDデータの補間）
- COT: 最大10日（週次データの営業日展開）

## 第4部: CNN 版と為替版の対応表

| CNN（株式版） | 為替版（本プロジェクト） | 変更理由 |
|--------------|----------------------|----------|
| S&P 500 vs MA125 | ペア価格 vs MA125 | 直接翻案 |

| 株 vs 国債リターン差 | 金利差（2Y+10Y）水準+勢い | 安全資産ローテーション → 金利差キャリー |

| （なし） | CFTC 投機筋ポジション | 為替固有: 先物市場のポジショニング |

| z-score（推定） | ローリング・パーセンタイル | レジーム変化への頑健性 |

### 重み設計の考え方

| 重み | 要素 | 理由 |
|------|------|------|
| **0.18**（最大） | モメンタム, 実現ボラ, 金利差 | 為替の主要駆動力（トレンド・ボラ・キャリー） |
| **0.14** | クロスアセット・リスク | グローバル要因だが直接のペア要因ではない |
| **0.12** | 52週レンジ位置 | モメンタムと相関が高い（冗長性の割引） |
| **0.10**（最小） | COT, breadth | 更新頻度が低い（週次）/ 適用範囲が限定的 |

## 第5部: 検証結果

### 2024年8月 キャリー巻き戻し

2024年7月〜8月に起きた歴史的な円キャリー巻き戻しで指数の挙動を検証:

| 時期 | F&G指数 | USD/JPY | COTスコア | 実現ボラ | 解釈 |
|------|---------|---------|-----------|---------|------|
| 2024年7月初 | **≈78**（強欲） | ≈161 | ≈99 | ≈8.8% | キャリー過熱・反転警告 |
| 2024年8月 | **≈7〜12**（極度の恐怖） | ≈142 | ≈0.1 | ≈15% | パニック・巻き戻し |

- **指数は「リスクオフ = 円高 = 恐怖」を正しく捉えた**
- 事前にCOTスコア99（極端な円ショート）が**反転リスクの警告**として機能
- COVID（2020年3月）でも極度の恐怖を記録

## 第7部: 既知の限界と今後の高度化

### 現在の限界

1. **インプライドボラの欠如**: 実現ボラは後ろ向き。真の「通貨VIX」にはインプライドボラが必要（有料）
2. **オプション・スキューなし**: 25Δリスクリバーサル（方向性リスクの市場価格）が取れない
3. **COT のラグ**: 週次・公表に3日のラグ → リアルタイムのポジション変化は捉えられない
4. **実現ボラの過小評価**: 終値ベースのため、日中の急変動を反映しにくい

### 将来の高度化案（有料データ利用時）

1. **1Mインプライドボラ**: 実現ボラ → ATMインプライドボラに差し替え
2. **25Δリスクリバーサル**: 第8要素として追加（コール/プットのスキュー = 方向性期待）
3. **Garman-Klass ボラ**: OHLC ベースで実現ボラの精度向上
4. **リテール建玉**: IG/OANDA のセンチメントデータを逆張り要素として追加
5. **経済イベントリスク**: BOJ/Fed/CPI の接近度を「不確実性プレミアム」として追加

## 付録A: 計算フローの要約

```
1. データ取得（日次）
   prices.py   → ペア終値 + リスクバスケット
   rates.py    → 金利（2Y/10Y × base/quote）
   positioning → CFTC ネットポジション（週次）
   breadth     → クロス円バスケット

2. 統合（load.py → build_dataset）
   ペアの営業日グリッドに全データを整列・ffill

3. 要素スコア算出（components.py）
   各要素の生シグナル → ローリング・パーセンタイル → 0〜100
   反転要素は 100 − percentile

4. 集約（index.py → aggregate）
   加重平均（NaN要素は重み再正規化で自動除外）

5. ラベル付け（index.py → label_for）
   0〜24: 極度の恐怖 / 25〜44: 恐怖 / 45〜55: 中立 / 56〜75: 強欲 / 76〜100: 極度の強欲
```

## 付録B: 用語集

| 用語 | 説明 |
|------|------|
| **Fear（恐怖）** | 投資家がリスクを避けている状態。為替では円高圧力 |
| **Greed（強欲）** | 投資家がリスクを取っている状態。為替では円安圧力 |
| **キャリートレード** | 低金利通貨（円）を借りて高金利通貨（ドル等）に投資する取引 |
| **キャリー巻き戻し** | キャリートレードが一斉に解消され、円が急騰する現象 |
| **セーフヘイブン** | 市場混乱時に資金が逃避する安全通貨（円・スイスフラン等） |
| **VIX** | S&P500のインプライドボラティリティ指数。「恐怖指数」とも呼ばれる |
| **実現ボラティリティ** | 過去の価格変動から計算した実際のボラティリティ |
| **COT** | Commitments of Traders。CFTCが公表する先物市場のポジション報告 |
| **パーセンタイル** | 過去のデータの中で現在値が何%の位置にあるかを示す指標 |
| **ffill（前方充填）** | 欠損値を直前の有効な値で補間する方法 |
| **和暦** | 日本の元号に基づく暦法。令和(R), 平成(H), 昭和(S)等 |
| **breadth** | 広がり。多くの銘柄/通貨が同じ方向に動いているかを測る |
