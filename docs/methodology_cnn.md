# ① CNN Fear & Greed Index の中身(解明)

出典: https://edition.cnn.com/markets/fear-and-greed
※ 本ドキュメントは CNN の公開説明 + 複数の独立解説(SoFi, public.com, finhacker, MacroMicro,
Investing News, Supertype)を突き合わせて再構成したもの。検証信頼度 約90%。
**CNN は正確な計算式・正規化の窓・スケーリング数式を公開していない** 点に注意(下記は公表された
「入力の説明」+ 第三者による再現の合成)。

## 1. 全体像

株式市場のセンチメントを **0–100 の1つの数値** に凝縮する指標。

- **0 = Extreme Fear(極度の恐怖)** … 投資家が過度に弱気・狼狽。
- **100 = Extreme Greed(極度の強欲)** … 投資家が過度に強気・楽観。

前提となる考え方: 「**恐怖**が行き過ぎると価格は本来価値より下に押し下げられ、**強欲**が行き過ぎると
価格は吊り上げられる」。2012年春に CNNMoney が考案。

7つの下位指標をそれぞれ 0–100 に正規化し、**等加重(単純平均)** で1つに合成する。各指標は
「**高いほど強欲(Greed)**」になるよう、必要なものは符号を反転させる。

## 2. 7つの構成要素

| # | 要素 | 何を測るか | 入力データ | 計算 | 反転 |
|---|------|-----------|-----------|------|------|
| 1 | **Market Momentum**(市場モメンタム) | 相場が地合い対比で上か下か | S&P500 と その **125日移動平均** | `S&P500 − MA125`。上=強欲 / 下=恐怖 | 否 |
| 2 | **Stock Price Strength**(価格の強さ) | 新高値/新安値による幅(breadth) | NYSE の **52週新高値 − 新安値** | 新高値超過=強欲 / 新安値超過=恐怖 | 否 |
| 3 | **Stock Price Breadth**(出来高の幅) | 出来高の推進力 | NYSE 上昇/下落銘柄の出来高 → **McClellan Volume Summation Index** | 上昇=強欲 / 下落=恐怖 | 否 |
| 4 | **Put and Call Options**(プット/コール) | オプション市場の逆張り的地合い | CBOE **総プット/コール比率の5日平均** | 比率↑(プット買い)=恐怖 | **是** |
| 5 | **Market Volatility**(ボラティリティ) | 予想変動率=「恐怖指数」 | **VIX と その 50日移動平均** | VIX が 50日MA 上=恐怖 | **是** |
| 6 | **Safe Haven Demand**(安全資産需要) | 株 vs 債券のローテーション | **株と国債の20日リターン差** | 株が勝つ=強欲 / 債券が勝つ=恐怖 | 否 |
| 7 | **Junk Bond Demand**(ジャンク債需要) | 信用リスク選好 | **ハイイールド債 − 投資適格債の利回り差** | スプレッド縮小=強欲 / 拡大=恐怖 | **是** |

### 各要素の補足
1. **モメンタム**: 125日(約6か月)MA との乖離。乖離幅の大小でスコアの極端さが決まる。
2. **価格の強さ**: 「52週高値の銘柄数 vs 安値の銘柄数」(CNNは差/比率の厳密式は非公表)。
3. **出来高の幅**: McClellan Oscillator(上昇−下落出来高の 約19日EMA と 約39日EMA の差)を累積した Summation Index。
4. **プット/コール**: **総**(equity+index)プット/コール比率の5日平均。比率が高い=弱気=低スコア(反転)。
   「1.0 を境に弱気/強気」は俗説的な単純化で、実際は相対的な乖離でスコア化。
5. **ボラティリティ**: VIX が 50日MA より高い=恐怖=低スコア(反転)。
6. **安全資産需要**: 過去20営業日の (株リターン − 国債リターン)。株優位=強欲。
7. **ジャンク債需要**: ジャンク債と投資適格債の利回り差(スプレッド)。狭い=リスク選好=強欲(反転)。

## 3. 正規化と集約

- **正規化**: 各指標の現在値を「自身の過去平均からの乖離を、普段の乖離幅(標準偏差)で割った」標準化
  に近い形で 0–100 にマッピング。再現実装では **z-score もしくは trailing percentile(直近1〜3年)** を使う。
  正確な窓・式は CNN 非公開。
- **集約**: 7つの 0–100 スコアを **等加重の単純平均** → headline 値。
- **ラベル境界**(0–100):

| 範囲 | ラベル |
|------|--------|
| 0–24 | Extreme Fear(極度の恐怖) |
| 25–44 | Fear(恐怖) |
| 45–55 | Neutral(中立) |
| 56–75 | Greed(強欲) |
| 76–100 | Extreme Greed(極度の強欲) |

(境界の整数は出典により ±1 程度ぶれる。CNN は「25未満=極度の恐怖」「55以上=強欲」等と緩く表現。)

## 4. 更新頻度

- ライブの headline 値は **米国市場の取引時間中に随時更新**(intraday)。
- 履歴の点は **日次(引け値ベース)**。
- 5日平均・20日リターン・移動平均など平滑化入力があるため、急変への反応にはラグがある。
- CNN は前日終値 + 1週間前/1か月前/1年前の値も併記する。

## 5. 既知の批判・限界(為替版を作る上での教訓)

1. **遅行指標**: 既に起きたこと(過去の価格・出来高・オプション)の要約で、将来予測力は限定的。
2. **逆張りの地合い計**であって割安/割高の判定ツールではない。「極度の恐怖=買い場」「極度の強欲=警戒」
   と読まれがちだが、極端な値が長く続くこともあり、単独のタイミング指標としては弱い。
3. **透明性の欠如**: 正確な式・重み・窓を非公開 → 第三者再現はばらつく。
4. **入力の相関**: モメンタム/強さ/幅/安全資産はいずれも S&P の値動きに相関 → 等加重でも実質的に
   「方向性モメンタム」を過大評価しがち。
5. あくまで **多数ある入力の1つ**(投資助言ではない)。

> ⚠️ 暗号資産の「Fear & Greed Index」(Alternative.me 等)は **全く別物**(BTCボラ・出来高・SNS等)。混同しない。

## 6. 為替版への示唆

- 7要素の枠組み(momentum / volatility / 安全資産需要 / 信用・キャリー / ポジション)は為替にも翻案可能。
- ただし **株式専用の要素**(NYSE新高値安値・McClellan・株プット/コール)は為替に直接対応物が無い → 為替固有の
  代替(オプション・スキュー、CFTC建玉、クロス円バスケット等)に置き換える。詳細は
  [methodology_usdjpy.md](methodology_usdjpy.md) を参照。
